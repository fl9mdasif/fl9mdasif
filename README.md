## About

I am a **Full-Stack Software Engineer** based in Dhaka, Bangladesh, with **3+ years of hands-on, client-project experience** building production web applications and AI-powered products. I take a feature from database schema to API to UI to deployment, and I own what I ship.

- Built and launched **Digital Pathshala**, a multi-tenant School ERP SaaS, live in production.
- Built **Sultan Bazar**, a live e-commerce platform with role-based access and order tracking.
- Built **VidMaxX**, an AI video SaaS that writes, voices, renders and publishes short videos.
- Build **RAG-powered AI chatbots** that answer from a business's own documents instead of guessing, with Python, FastAPI, LangChain, ChromaDB and OpenAI, plus human handover and lead capture.
- Ranked in the **top 5% of software engineers assessed globally** in the bKash Pro5 technical assessment, 2026.
- **B.Sc. in Computer Science and Engineering**, BUBT.
- Founder of **[Interactive Software Care](https://isoftwarecare.com)**, a software agency.

**Currently:** open to full-time remote roles, and relocation roles in the US, Canada and Europe.
